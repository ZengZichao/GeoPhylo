# ADR-6：把图面质量开关做成显式开启项，默认保持保守

- **状态**：已采纳（自渲染覆写版本起生效；API 为增量变更）
- **记录日期**：2026-10-26
- **代码**：`geophylo/render/ticks.py`（`format_age_exact`）、
  `geophylo/render/labels.py`（`_candidate_sequence`、`apply_label_degradation`、
  `_collides`）、`geophylo/render/linear.py`（`add_geo_axis`）、
  `geophylo/render/result.py`（`RENDER_PARAMS`、`validate_render_params`）、
  `tests/test_labels.py`、`tests/test_ticks.py`

> 本文件是 [ADR-6-render-overrides-opt-in.md](ADR-6-render-overrides-opt-in.md)
> 的中文译本；英文版为权威版本，以英文版为准。

## 背景

发表级图表需要四种行为，而库刻意没有实现它们——因为每一种都可能凭空补出源数据
并不携带的信息：

| 需求 | 库为何拒绝 |
| --- | --- |
| 把 `251.902 Ma` 印成 `251.902` 而非 `252` | `format_age()` 对 `age >= 100` 取整到整 Ma，快照精度到不了图面 |
| 一条条带只用一种语域（`T3 · J1 · K1`，而非 `T3 · J1 · Lower Cretaceous`） | 缩写逐区间独立判定，条带里可能代号与全名混排 |
| 没有官方别名时也要有标签（`Aalenian -> Aal`） | 缩写门禁拒绝名称前缀截断，因为截断后的名字是读者无法解码的记号 |
| 同轨相邻标签之间至少 4 pt 净距 | 碰撞判定只看框是否相交，两枚标签可以零间隙相贴、糊成一个不存在的词 |

下游图表脚本往往在这四点上于脚本层做补偿，等于公共 API 画不出发表级的图，
必须每个项目各自打补丁。本记录消除的正是这个局面。

## 决定

给 `add_geo_axis()` 增加四个**显式开启**参数，默认值一律不变：

| 参数 | 默认 | 设置后的作用 |
| --- | --- | --- |
| `tick_format` | `"default"` | `"exact"` 按存储精度打印（`format_age_exact`）；也可传入 `age -> str` 可调用对象 |
| `track_register` | `"interval"` | `"uniform"` 时，一条**条带**里只要有一个区间被迫缩写，整带改用官方代号 |
| `fallback_truncation` | `None` | `n >= 2` 时在隐藏之前加入 `n` 个字符的名称前缀候选（必要时递减到 2） |
| `min_label_gap` | `0.0` | 同一条带内两枚标签沿时间维的最小净距（pt） |

两条顺序规则是决定本身，不是实现细节：

1. **截断排在旋转之后。** 阶梯为：全名 → 缩写 → 缩写旋转 → 全名旋转 → 名称前缀 → 隐藏。
   旋转保住"按原样读出全名"，截断是"造新记号"。若把截断排在前面，本可用旋转
   读出全名的标签会被无谓截短。
2. **`track_register` 按条带分组，不按调用分组。** 一次 `add_geo_axis()` 里每个
   rank 各占一条条带；"同轨"指一条条带。若按调用分组，一条拥挤的 rank 会把其余
   rank 一起拖成代号。

计数以 `labels_shortened_n` / `labels_rotated_n` 落在结果对象上（统计**可见**标签），
图注可直接引用库自身的诊断字段，而不必从私有的 item 列表重新求和。

## 被否决的替代方案

- **把论文图的策略做成默认值。** 否决：默认值就是库的科学立场——不凭空造记号、
  不掩盖"名字放不下"这个事实。把截断或取整做成静默默认，会让每一张下游图表
  都继承这些选择。
- **只切换刻度格式的 `precision="snapshot"` 开关。** 否决，面太窄：凡是打印年龄的
  场景都有同样的需求，因此旋钮是格式化器本身（`tick_format="exact"` 或可调用
  对象），而不是一次性模式名。
- **把标签渲染整个交给回调。** 否决：回调会把布局策略彻底推出库外，在更高一层
  重新制造脚本层问题。四个窄参数让几何契约（厚度维硬约束、时间维不出条带）留在库内。
- **库有了 `min_label_gap` 之后就删掉图脚本的 `guard_same_track_gaps` /
  `hide_track_overflows`。** 否决：它们现在用真实字形度量**复核**渲染结果，而解析
  估算看不到这层差别。实测丢弃数为 0，可当作回归警报保留。

## 后果

- 既有调用方不受影响：四个默认值逐位复现旧行为。
- 只靠公共 API 就能画出与已发表版式一致的图，调用方不再需要库侧补丁。
- 加参数是增量变更；改**默认值**不是，必须新开一条记录而不是改写本条。
- 每个旋钮的语义都有独立于图表的测试钉住（`tests/test_labels.py`、
  `tests/test_ticks.py`），因此未来改默认值不可能靠"图没变"蒙混过关。
